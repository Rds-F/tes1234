# Web Coding Competition 2026 - Peserta 1

Aplikasi web contoh untuk pengujian deployment otomatis di Coolify.

## Fitur:
- Zero-dependency Node.js HTTP Server.
- Responsive modern UI dengan Dark Mode & Glassmorphism.
- REST API `/api/status` untuk monitoring memory & uptime realtime.
- Teroptimasi untuk Coolify Nixpacks builder (1 vCPU, 2GB RAM).
